# Observation — version 1.18.3

Captures natives en français aux tailles 1440 × 960, 1100 × 800 et 900 × 700.
Les fichiers `observation-sky-*` montrent la Lune calculée localement, une vue
boussole du ciel, la direction et la hauteur. `observation-name-place-*` montre
la saisie du libellé d’un site, avec les coordonnées et le fuseau conservés.
Les autres captures reprennent le parcours complet avec les libellés actuels.

Le test de curseur utilise des événements de souris avec le bouton maintenu,
pour vérifier les actualisations avant relâchement dans les quatre vues.
Les images fixes documentent la composition ; elles ne mesurent pas la cadence
sur un ordinateur donné. La vue Ciel représente un horizon théorique plat,
pas le relief observé sur place.
